10 phút đã trôi qua. Bạn có muốn bắt đầu lại không?

💡 Giải thích logic tư duy lập trình

  • Tránh memory leak với setInterval:
    • Lưu timerId, luôn clearInterval(timerId) trước khi tạo interval mới và khi pause/reset/hết giờ — không để nhiều interval chạy song song.
    • Dọn dẹp bằng window.addEventListener('beforeunload') khi rời trang.
  • Độ chính xác: Không đếm trừu tượng (-1s mỗi tick) vì tab ẩn bị trình duyệt làm chậm. Thay vào đó lưu endTime = Date.now() + remaining, mỗi tick tính remaining = endTime - Date.now() — tự đồng bộ với đồng hồ hệ thống.
  • Animation dưới 1 phút: Khi remaining ≤ 60000ms thêm class warning → kích hoạt @keyframes pulse + đổi màu đỏ. Vòng tròn cập nhật stroke-dashoffset.
  • Hết giờ: clearInterval, hiển thị modal tự tạo (không dùng alert() chặn luồng), phát tiếng bíp qua Web Audio API.
  • Tích hợp Domain/Hosting & đồng bộ server: Khi deploy, client Date.now() có thể sai do người dùng chỉnh giờ máy. Giải pháp: lúc tải trang gọi API server (vd GET /api/time) lấy serverTime, tính offset = serverTime - Date.now(), sau đó dùng Date.now() + offset. Với đếm ngược đến mốc cố định (sự kiện/khuyến mãi), nên tính mốc hết giờ theo server và truyền về client.
